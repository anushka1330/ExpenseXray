# 🤎 Expense X-Rray

> **See What Your Money Doesn't.**
> 
> Your spending has patterns.
Your goals have a story.
It's time to see them.

✦ Create your X-Ray ID today.

Expense X-Rray is a personal finance web application designed to make expense tracking **simple, visual, and insightful**. Track your spending, manage budgets, set savings goals, and understand your financial habits through intuitive dashboards and charts.

---

## ✦ Features

* 📊 **Interactive Dashboard** — Get a quick overview of your finances
* 💸 **Expense Tracking** — Record and organize your daily expenses
* 📈 **Visual Reports** — Understand spending patterns through charts
* 🎯 **Savings Goals** — Set goals and track your progress
* 💰 **Budget Management** — Create and monitor spending budgets
* 🔐 **Authentication** — Secure login and signup flow
* 👤 **Profile Management** — Manage your personal account
* ✨ **Modern UI** — Warm, minimal brown & beige aesthetic
* 🗃️ **Database Migration** — Built-in support for database updates

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anushka1330/ExpenseXray.git
cd ExpenseXray
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r expense/requirements.txt
```

### 4. Run the application

```bash
python expense/app.py
```

Open the local application in your browser.
